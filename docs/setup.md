# Local setup

## Small reproducible advisor preview

This path needs no running database server, Redis, cloud service, or real account.

1. In `SmartCourse-Server`, run `mvn verify` with Java 8 or 17 and Maven.
2. In `SmartCourse-App`, run `npm ci --ignore-scripts --no-audit --no-fund`.
3. At the repository root, run `python scripts/preview_advisor.py` (or `py -3.12 scripts/preview_advisor.py` on Windows).
4. Open `http://127.0.0.1:19531/`.

Use `--port 19532` if the port is occupied. The server binds only to `127.0.0.1` and exposes a fixed set of preview assets and fixtures. Stop it with Ctrl+C. The JSON fixtures are regenerated by JDBC tests, and the Vue component is recompiled each time the preview starts.

## Student production build

The current Vue 2/CLI 4 application uses Webpack 4. On modern Node.js, enable its legacy OpenSSL provider for the build process:

PowerShell:

```powershell
cd SmartCourse-App
$env:NODE_OPTIONS = '--openssl-legacy-provider'
npm.cmd run build
```

POSIX shell:

```sh
cd SmartCourse-App
NODE_OPTIONS=--openssl-legacy-provider npm run build
```

The workflow uses Node.js 22. Existing Sass deprecation and bundle-size warnings remain. This compatibility setting does not modernize the dependency stack.

## Full local application

The complete application requires a dedicated MySQL demo database and Redis. Defaults are MySQL `localhost:3306/online_edu`, Redis `localhost:6379`, and the following application ports:

| Entry | Port |
| --- | --- |
| Portal | 9527 |
| Student | 9530 |
| Teacher | 9529 |
| Admin | 9528 |
| Backend | 9096 |

The existing Windows launcher is [start_smartcourse.bat](../start_smartcourse.bat). It prompts for the database password and whether to import/reset the demo schema. The backend also runs [DatabaseMigrationRunner](../SmartCourse-Server/src/main/java/xyz/refrain/onlineedu/config/DatabaseMigrationRunner.java), which performs migrations and seeds/updates demo data at startup. Use an isolated demo database rather than a database with records you need to retain.

The launcher inherits `MYSQL_PWD` and supplies an absolute upload path. When launching the backend directly from `SmartCourse-Server`, set `MYSQL_PWD` and use the default relative `../uploads/`, or override `SMARTCOURSE_UPLOADS`. Standard Spring datasource environment overrides can select a separate MySQL instance. No database password is needed for `mvn verify`.

Read [部署说明.txt](../部署说明.txt) and [TEST_ACCOUNTS.txt](../TEST_ACCOUNTS.txt) for the existing demo workflow and accounts. These are local demonstration accounts, not accounts for a hosted service. This round verifies the advisor module, fixture preview, and student production build; it does not establish that every legacy platform workflow is production-ready.
